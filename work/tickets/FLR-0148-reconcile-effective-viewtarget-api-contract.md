## Inferences

- The explicit camera result rejects “the Planetarium camera alone hides the
  origin cube” as the sufficient explanation.
- The common QEMU, Vulkan present, and Wayland child path is not globally
  broken: the earlier positive control and current present markers prove that
  those boundaries can work. The current failure is conditional on the
  effective image/source path or on which pixels reach the top-level
  compositor.
- A source patch made against the incomplete Devtool context could appear to
  apply successfully while targeting the wrong API generation. Source
  provenance must therefore be fixed before another non-trivial patch.
- The current runtime evidence moves the first unproven boundary earlier than
  Wayland composition: no evidence yet proves that the active Filament `View`
  points at `native_diagnostic_scene_` at draw time. The new diagnostic patch
  measures that identity directly; until it is built and run, the owner of the
  black pixels remains UNKNOWN.
