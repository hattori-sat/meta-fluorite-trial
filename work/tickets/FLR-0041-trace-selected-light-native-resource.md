## Problem

FLR-0040 corrected the invalid GUID138 comparison. A changed selected GUID134 still produced HUD-only, while an earlier selected GUID136 change produced native 3D pixels. The static call path shows both selected lights should reach native creation, but the current runtime trace does not identify the actual Filament entity/resource/render-list state.

## Purpose

Add the smallest diagnostic trace needed to compare GUID134 and GUID136 at the native operation boundary, using the Mac Devtool source workflow and an official Devtool-generated patch. Then build the patch on the Mini PC and validate the trace and pixels in QEMU.

## Success measure

- The trace records, for GUID134 and GUID136, the selected-light ordinal, native entity id, Filament light component/build result, scene membership, and render-list/frame status without changing production behavior when disabled.
- Mac source edit is made in the persistent Devtool workspace; the patch is generated by Devtool and placed under `meta-fluorite-trial` using the established recipe registration.
- The project commit is bundled to the Mini PC; the fixed receiver/build/TMPDIR are reused; `do_patch`, `do_compile`, and the image build pass.
- QEMU control plus GUID134/GUID136 selected-light comparisons are captured only through QMP, with logs, hashes, teardown, and explicit distinction between facts and hypotheses.

## Facts

- At `FLR0026_NATIVE_LIGHT_LIMIT=6`, GUID134 (ordinal 4) and GUID136 (ordinal 5) are selected; GUID138 is not.
- Static source trace maps selected lights through ECS entity/component creation to `BuildLightAndAddToScene`, which builds a Filament light and adds its entity to the scene.
- FLR-0040: both control and selected GUID134 override had 16 frame begin/end/event-returned cycles, no fault markers, and HUD-only QMP pixels.

## Hypotheses

1. GUID134 and GUID136 differ in native entity/resource state or scene membership. Prediction: the new trace exposes a mismatch before render.
2. Native state matches, but the frame/render-list or Wayland composition state differs later. Prediction: native traces match and the divergence appears at frame/render/present or surface composition.
3. The earlier GUID136 3D result is not reproducible under the current fixed image/profile. Prediction: a fresh GUID136 comparison is HUD-only.
