scene, render target, present, or Wayland composition semantics.

### Act

H1 is falsified: the active native pipeline has color writes enabled and mask
15. H2 is falsified: the render area, viewport, and scissor cover the full
target. H4 is not supported as the sole cause because QMP independently shows
the native 3D region black. H3 remains, but the state trace narrows it to
fragment/material input or another shader/attachment-content path rather than
the already-confirmed geometry admission, viewport, color mask, or present
boundary.

The next source owner is the Material API contract. The fixture declares the
`color` uniform and calls `native_diagnostic_material_->setDefaultParameter()`
before creating `native_diagnostic_material_instance_`. Filament's API defines
that call as writing `Material::getDefaultInstance()`, while the Renderable is
bound to the separate `createInstance()` result. FLR-0153 will change only the
active instance binding and repeat the same build/QMP loop.
