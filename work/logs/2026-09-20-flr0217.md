## Outcome

Existing runtime diagnostics prove that the readback operation targets a real
swapchain render target and completes successfully, but they do not yet prove
that the callback payload belongs to the same swapchain image index that was
presented. The payload is uniformly 255 while the paired native-only QMP ROI is
black. The next diagnostic is direct image-index correlation.

## Facts

- Reused the FLR-0216 rootfs, fixed receiver/build/TMPDIR, and one QEMU run.
- QMP native-only frame SHA-256:
  `b133eeb9e9e1fe49188d717d3649a3aba3ebaf006643eafafd1b215605c05147`.
- Native ROI `[300,250,620,400]`: `changed_pixels=0`,
  `chromatic_pixels=0`, all black.
- HUD ROI remained visible with `changed_pixels=2976` and
  `chromatic_pixels=2801`.
- Target marker: `target_handle=236 swapchain=true extent=1280x800`.
- Target color format/layout: `44/9`; readback source identity was logged.
- Readback stages: queue submit result 0, fence wait result 0, map result 0,
  reshape success, cleanup success.
- Present marker before readback: queue present result 0, index 0.
- Driver readback payload: `4096000` bytes, all bytes non-zero; ROI all
  `248000` RGB-positive, alpha min/max `255/255`.
- QMP evidence and selected runtime log are retained under the FLR-0217
  evidence role path on Mini; raw addresses are not copied into Git.
- Teardown PASS: QMP quit accepted; host residual QEMU, runqemu,
  flutter-auto, and QMP socket counts were zero.

## Inferences

- This is not an API return-code failure in the readback path.
- The uniform payload cannot be treated as proof of rendered 3D content because
  it does not match the black final QMP native surface.
- The remaining ambiguity is image identity/timing, not patch application.

## Hypotheses

1. `readPixels` reads a different swapchain image than the one presented.
2. The readback is synchronized but observes a cleared/placeholder image before
   the actual native content becomes visible.
3. The QMP compositor presents a different surface/image than the traced
   swapchain target.
