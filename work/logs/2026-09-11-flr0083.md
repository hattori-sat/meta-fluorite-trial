# FLR-0083 — current-image command-stream execution boundary

## Plan

Map the current Filament command-stream and Vulkan present path from the p16
enqueue markers to the missing execution markers. No source edit or build is
allowed before the static boundary is identified.

## Facts

- p16 current-image minimal geometry reached frame begin and renderer enqueue,
  but emitted zero command-execution, queue-present, and commit-done markers.
- The marker strings are present in the guest `flutter-auto` binary.
- Historical FLR-0042 reached visible cube pixels and the present boundary.

## Inferences

- The leading boundary is command-stream worker/dispatcher execution, not
  production light/model content and not yet Flutter parent opacity.

## Hypotheses

- Worker/dispatcher does not drain the current queue.
- The commands use a path not covered by the named trace.

## UNKNOWN

- Exact worker owner and first blocked operation.
