## Correction — filesystem hypothesis superseded (2026-09-10)

The later direct probes corrected the Iterations 9–12 hypothesis. The existing
state bind itself accepts both a non-root FIFO and nested
`cp -afl --preserve=xattr`; the earlier FIFO failure occurred because stale
`TMPDIR/work` directories were `root:root`. The container-local tmpfs path was
therefore an unnecessary experiment and is not part of the final contract.

The final wrapper keeps project, AGL, build, downloads, sstate, and TMPDIR in
the requested single bind. It repairs only ownership of those fixed paths,
probes the exact FIFO/xattr operations, and stops before Devtool if they fail.

The ownership repair only changes real directories and regular files. It does
not follow or modify stale/dangling symlinks, which are not writable state
objects and must not block startup.

The repair checks each candidate with `test -e` immediately before `chown`, so
an invalid directory entry that disappears during traversal is skipped rather
than treated as a reason to delete or rebuild the state.
