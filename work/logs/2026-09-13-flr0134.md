### Inferences

- The normal 3D failure is not currently a global QEMU, Wayland, Vulkan
  present, camera, or ViewTarget frame-admission failure.
- `FLR0026_SHAPE_READY` is weaker than “visible geometry”: it proves the
  RenderableManager component exists, while the target trace proves only that
  the renderer visited a 36-index draw. The fixed-region comparison is still
  required for visual acceptance.
- The first actionable Dart/native API mismatch found after the frame boundary
  is Light color serialization: Dart `Light.toJson()` emits `color` as a
  `Float64List` RGBA vector, while native `Light::Light` decodes `color` into a
  string and `LightSystem` passes that string to `colorOf()`. In the current
  run the native parser therefore cannot use the explicit Dart color and falls
  back to its default color-temperature path. This is a confirmed contract
  mismatch, but its sufficiency to explain the black cube is UNKNOWN until
  FLR-0135 runs.
