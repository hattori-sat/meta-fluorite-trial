### Inferences

- The 2D HUD path is healthy enough to reach the QMP framebuffer, and 2D/3D
  composition is possible for the self-made fixture. A general compositor
  incapability is therefore not the best explanation for the current
  production-only black ROI.
- Current QMP has no visible vehicle pixels; the HUD cannot be declared the
  cause merely because it is present. The current run did not disable the HUD,
  so a black top-level surface/stacking contribution has not been directly
  falsified either.
- The strongest current observation is downstream of production scene setup:
  asset/model/Scene and texture binding markers occur, while the visible 3D ROI
  remains black and Vulkan Present does not return. This correlation does not
  yet prove a single cause.
- Photo 1 is a static emissive atlas. It is neither proof that Sequoia appears
  when the HUD is absent nor proof that runtime texture sampling works.

### Hypotheses

Ranked hypotheses:

1. **Production Present/Lavapipe synchronization or completion boundary.**
   If this is the current first blocker, FLR-0344's same-image watch will show
   an unsignaled sync field or a missing writer while Present remains entered;
   a returned/signaled wait without QMP pixels would move the boundary later.
2. **Behavioral regression between the historical Sequoia-positive profile and
   the current image/source stack.** If true, a matched source/image/profile
   replay or narrow change-range comparison will recover a changed behavior;
   current records cannot falsify it because rootfs/source/profile identities
   differ. A regression is plausible, not proven.
3. **HUD/window stacking hides an otherwise-produced native surface.** A
   controlled HUD-off or owner-isolation A/B on the exact current image would
   expose pixels if they exist behind the Flutter surface. The fixture and
   historical combined frame weaken a global stacking failure, not this
   production-specific possibility.
4. **Production material/shader/fragment output drops pixels after binding.**
   If true, the Present boundary should complete while the production ROI stays
   black; the unlit magenta probe currently weakens a lighting-only version.
5. **Camera or missing texture/light alone.** Existing camera and asset/binding
   observations make these lower priority as sole explanations of a fully
   black ROI; none is conclusively ruled out for a future partially visible
   result.
