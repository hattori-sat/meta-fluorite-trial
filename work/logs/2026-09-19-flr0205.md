# FLR-0205 working log

## Plan

- Reuse the FLR-0204 image with no source change.
- Observe client Wayland protocol and AGL compositor journal, then pair the
  result with QMP screen evidence.

## Facts / hypotheses

- H1: native buffer attach/commit or release is missing.
- H2: client and compositor protocol are positive, but parent-frame composition
  hides the native buffer.

  `flutter-auto` with `WAYLAND_DEBUG=client`.

## Conclusion

The client-side Wayland attach/commit and Vulkan present path is positive; the
compositor reports no error. The missing boundary is narrowed to the content
of the WSI `wl_shm` buffer or its compositor import/composition. FLR-0206 owns
the bounded syscall/mapping observation.
