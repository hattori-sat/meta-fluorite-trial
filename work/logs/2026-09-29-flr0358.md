### Inferences

- The narrow test seam is the real `serial-exec` CLI plus the unchanged
  official gate validator, with only the external serial endpoint simulated.
- A valid setup response should consist only of the expected command echo (or
  no echo), CR/LF framing, and exactly one expected prompt at the end. Any
  unexpected or trailing response must fail closed before the requested
  command is sent.
