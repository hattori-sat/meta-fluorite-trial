### Facts

- Read-only Mini SHA-256 checks reproduced the four focused hashes in the

- The candidate rootfs contains `/usr/lib/libLLVM.so.18.1`, inode 5719,
  107,835,552 bytes, Build-ID
  `359c1108040bc6bc1af64bb639d0b25385858051`. Its PT_LOAD layout agrees with
  the runtime mapping: map start `0x7f1c3ba3d000`, file offset `0x838000`,
  runtime RIP delta `0x2e5541`, and calculated ELF VMA `0xb1d541`. Exact file
  bytes and saved Oops bytes agree. This falsifies wrong-image and
  load-bias/file-offset arithmetic explanations for this artifact set.
- At ELF VMA `0xb1d540` the bytes begin `ff cf`; saved RIP is the second byte
  (`cf`) followed by `83 ff 07`. Intel Vol. 2A defines bare `CF` in 64-bit
  mode as 32-bit IRETD; IRETQ requires REX.W.
- The exact Mini QEMU binary is version 8.2.7, SHA-256
  `8cb2c6f4700a4bda5145b92cb28e38662d62ff820ecf8dbb6a8f0dd47ea4e4af`.
  The existing native source workdir is
  `$BUILD_DIR/tmp/work/x86_64-linux/qemu-system-native/8.2.7/qemu-8.2.7`;
  `VERSION` is 8.2.7 and `target/i386/tcg/seg_helper.c` SHA-256 is
  `36afbc2828fda15e3c62c577dfe7c72548defd30fd35ef6c12ec9131e1f054cf`.
- In that exact source, opcode `CF` reaches `helper_iret_protected` with
  `dflag-1`; `shift==1` enters `POPL_RA`, which uses `SEG_ADDL`'s 32-bit cast
  and `cpu_ldl_kernel_ra`. `get_sp_mask` selects `0xffffffff` when the cached
  SS descriptor has `DESC_B_MASK`, `0xffff` otherwise, and zero for
  `DESC_L_MASK`.
- Saved Oops registers: RIP/R10 `0x7f1c3bd22541`, RSP
  `0x00007f1bd9486750`, RFLAGS `0x217`, CS `0x33`, SS `0x2b`. Kernel report:
  user-mode supervisor read, error code `0`, CR2 `0xd9486750`.
- The saved QEMU launch command has `-machine q35`, `-cpu qemu64`, `-smp 4`,
  and `-m 6144`; it has neither `-accel` nor `-enable-kvm`. QEMU 8.2.10's
  official docs state TCG is the default, but the active 8.2.7 backend was not
  explicitly queried in that run and stays UNKNOWN here.
- No persistent rootfs extraction, source modification, BitBake action, cache
  operation, or QEMU operation occurred. Candidate and native source artifacts
  were read in place; the rootfs ELF stream was made seekable through a
  transient memfd only.

### Inference / hypothesis / UNKNOWN

  SS.B=1, then `uint32_t(0 + (RSP & 0xffffffff))` is exactly

  mechanism match, not proof those cached runtime conditions held.
- **Inference:** R10==RIP is compatible with an indirect transfer but does not
