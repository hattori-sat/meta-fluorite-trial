# FLR-0319 working log — production material/texture binding

## Plan

- Carry forward FLR-0318's rejection of duplicate primary/secondary Scene
  attachment.
- Inspect the production GLB and loader/material contract before changing
  source.
- Use one narrow runtime probe only if static evidence leaves the binding
  boundary unknown.

## Facts / hypotheses / decisions

- Historical FLR-0049 shows red tail-light pixels from the production Sequoia
  path; current FLR-0317 and FLR-0318 do not.
- FLR-0318's secondary-only runtime still creates `PaintColor`, `HeadLights`,
  `Glass`, and other material instances, reaches true frames and submit, and
  produces native ROI `0/144000`.
- Leading hypotheses are missing texture/sampler binding, post-material
  pipeline discard, or an asset revision mismatch.
- The source GLB and the deployed Mini rootfs asset have the same SHA-256:
  `cde9efd067a75c1f5b99b8fb529b5bb4636956193188bd15add3bccc349109ec`.
  The asset is 13,671,064 bytes.
- Static GLB inspection maps the `HeadLights` material to an embedded PNG
  `HeadLights_Emission` image through the emissive texture slot, with
  emissive factor `[1,1,1]`. The derived 1024x1024 image visibly contains the
  red tail-light bands; its SHA-256 is
  `87fa31842d2e6e97aeefdb29de38e8e070619607ef93fda071915d6856362546`.
- This rejects the asset-revision hypothesis and confirms the user's
  distinction: the red tail-light data exists without requiring a new scene
  Light. The open problem is where runtime material/texture data stops
  reaching the native QMP pixels.
- Filament 1.65.4 source shows the expected distinction: `emissiveIndex` is an
  integer UV selector, while `AssetLoader` binds the actual embedded texture
  through `emissiveMap` and `FFilamentAsset::applyTextureBinding`.
- Fluorite waits for `asyncGetLoadProgress() == 1.0` before dispatching the
  queued model to Scene, but existing markers do not prove the internal
  gltfio dependency graph has applied every texture binding.

  `84936ab17f74ce74540121345ee14075b3c4d8b9d113f909f0ceb1749dbc148b`.
  Full parameter slice SHA-256:
  `a3b697102ce1a2cd4822f9bf5ad962aca2a3bb4d5c5c0d1c77463202bdbd5f51f`.
- QMP quit and residual-target cleanup passed. The first post-quit process

## Decision

Static inventory and the Fluorite-side parameter contract are complete. The
next ticket must instrument the internal gltfio ResourceLoader/TextureProvider
completion and `emissiveMap` setParameter boundary. No Light or body-color
patch is allowed until that boundary is identified.
