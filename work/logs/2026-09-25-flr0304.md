## Do

FLR-0302 established that production Sequoia transform attachment is valid but
native pixels remain absent. Static source/API inspection found:

- Filament Camera exposes projection, culling-projection, view, and position
  getters, so the effective camera can be recorded without changing behavior.
- Filament RenderableManager exposes `setCulling()` but no culling-state
  getter. The default state is therefore UNKNOWN unless an explicit A/B is run.
- The existing culling switch is only in `addLoadedModelsToScene`, the
  diagnostic Scene path. It does not reach production `setupRenderable`.

`FLR0304_PRODUCTION_DISABLE_CULLING`. The normal production path is unchanged.
