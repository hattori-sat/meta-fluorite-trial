# FLR-0086 — present-call completion boundary

## Plan

Use the FLR-0084 runtime evidence as the baseline. Inspect the effective
Filament Vulkan present path, compare semaphore/llvmpipe and Wayland-release
hypotheses, then create one neutral Devtool-generated trace before any
behavior change.

## Facts

- The preceding fixed QEMU run reached `VK_QUEUE_PRESENT_BEGIN` but not the
  present-boundary completion marker.
- The same QMP frame showed the 2D HUD and zero native candidate pixels.
- GDB showed live engine/Vulkan activity in llvmpipe/Vulkan wait frames.

## Inferences

- The present call or its immediate GPU/WSI wait is now the highest-value
  boundary to instrument.

## Hypotheses

1. Finished-drawing semaphore or llvmpipe completion is not satisfied.
2. Wayland buffer release/child-surface completion is missing after present.
3. Present completes but composition hides the native buffer.

## UNKNOWN

- The exact function/state responsible for the first present-side wait.

## Runtime evidence — 2026-09-11

### Facts

- The serial harness initially exposed two evidence defects: its completion
  marker was read before the status field, and the parser then required a byte
  after the terminal marker. FLR-0087 fixed both; the final Mini receiver
  revision was `e69f1364552dfe677fbc3c7050043e7172f6e761`.
- A first background launch failed before the app started because root-created
  log/PID files were not writable by `agl-driver`. The corrected command let
  `agl-driver` create its own files. This was a launch-script ownership error,
  not an image or app verdict.
- A bounded foreground run proved the app stays alive for eight seconds and
  reached engine creation, llvmpipe Vulkan selection, model/light/shape setup,
  Wayland surface creation, frame begin/end, and the first present-side wait.
  Its deliberate timeout returned status 124.
- The final background run proved exactly one `flutter-auto` process. QMP
  captured early/late screenshots and 16 QMP-only video frames under
  `$QEMU_EVIDENCE_ROOT/flr0086-86dddbb/`.
- The late QMP frame is 1280x800 with SHA-256
  `16ccbabf47c6f5de8b47230e339bd090091a8923cfa377c105ec853fc2e97241`.
  Native `[300,80,620,360]` is `0/223200`; HUD `[200,100,400,250]` is
  `1214/100000`. The frame visibly contains the HUD/metrics and controls but
  no 3D object.
- The new opt-in trace emits exactly one each of `PRESENT_ENTER`,
  `PRESENT_FLUSH_DONE`, `PRESENT_CALL_BEGIN`, and `QUEUE_PRESENT_ENTER`, then
  zero each of `QUEUE_PRESENT_RETURN`, `PRESENT_CALL_RETURN`, and
  `PRESENT_DONE`.
- QMP quit returned PASS, cleanup returned PASS, the host residual-target
  count was zero, and the QMP socket was absent.

### Inferences

- 2D Flutter composition, engine creation, scene setup, and the initial Vulkan
  submit are not the first failing layer in this run.
- The highest-value remaining boundary is the synchronous wait inside or
  immediately below `vkQueuePresentKHR`, before any post-present Wayland
  release or composition completion.

### Hypotheses

1. The present wait semaphore is not signaled by the preceding submit or is
   not observed by llvmpipe.
2. llvmpipe's queue-present implementation blocks on a fence/condition
   variable before returning to the caller.
3. The WSI call returns but the trace is misplaced. This is now lower priority
   because the queue-present entry is followed by a stable black native region
   and no return marker.

### UNKNOWN

- Exact wait symbol, semaphore state, and queue-submit signal relationship.
- Whether the same wait boundary is shared by the self-made fixture and the
  production Sequoia route.

### Decision

FLR-0086 is complete as a diagnostic boundary unit. No present/semaphore
behavior change was accepted. FLR-0088 owns the next bounded static + GDB /
syscall runtime investigation.
