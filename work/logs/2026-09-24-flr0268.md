## Inferences

- The image, Flutter parent, Wayland display, and SHM control path can still
  display 2D plus a self-made 3D cube after FLR-0267.
- Readback mode is the first changed boundary associated with the new full-black
  frame; release starvation is not sufficient to explain it.
- Delayed capture after the readback release events did not restore the frame,
  so the simple startup timing hypothesis is rejected.

## Hypotheses

1. The enlarged shared pool or the offset readback buffers change the visible
   SHM surface/compositor state and blacken the whole frame.
2. The readback publish/flush path changes the parent surface independently of
   the SHM buffer allocation.
