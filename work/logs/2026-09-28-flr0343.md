### Plan

### Facts

- FLR-0341's exact-image stack reached Lavapipe `cnd_wait` and
  `wsi_common_queue_present`; its later submit signal handle matched Present's
  wait handle. The stack's `sync` pointer differed from the handle by 88 bytes.
- Exact runtime/debug ELF DWARF reports `vk_semaphore.permanent` at offset 88,
  `lvp_pipe_sync.base` at offset 0, and the `lvp_pipe_sync` fields at
  `signaled` offset 104 and `fence` offset 112. The pointer delta is an exact
  layout match; same-run handle conversion/identity still needs confirmation.
- FLR-0342 corrected the source interpretation: `cnd_wait` precedes the
  `VK_SYNC_WAIT_PENDING` test in the runtime function and matching Mesa source.
  The actual field values and writer were not observed.
- Current Mini preflight found zero `qemu-system-x86_64`, `runqemu`, and
  `flutter-auto` processes. The existing FLR-0342 evidence directory contains
  two regular Lavapipe ELF files. The FLR-0343 evidence slot will be checked
  again by the ticket runner immediately before creating it.
- Mini evidence storage had `68,413,632 KiB` available and guest-QEMU host
  memory availability was `28,287,668 KiB` at preflight.

### Inferences

- A single selected-object watchpoint run can distinguish a field transition
  from a bounded no-transition result without changing the production image.
- The GDB/watchpoint run may perturb timing; its result diagnoses the object
  state but cannot by itself prove uninstrumented rendering behavior.

### Hypotheses

1. A producer writes `signaled` or `fence` during the Present stall; a hardware
   watchpoint will identify the writer stack.
2. Neither field is written during the eight-second window; this localizes the
   missing event but does not prove the producer is globally absent.
3. The captured `sync` pointer is the logged semaphore's `permanent` member;
   in the new run, handle + 88 must equal `sync` to validate the layout mapping.

### UNKNOWN

- Runtime field values/writer, fresh-run handle-to-sync mapping, wait return,
  and causal relationship to black production QMP pixels.
- Whether any existing HUD-off control is relevant; this ticket does not
  change or suppress the HUD.

3. The Present wait's signal/fence fields remain either unwritten or written
   outside this unobserved interval; this run did not discriminate them.
