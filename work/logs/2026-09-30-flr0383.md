## Purpose

Test one bounded production intervention: apply the known-visible blue UNLIT
material to every renderable primitive of `sequoia_ngp.glb`, then verify live
Sequoia and 2D HUD pixels together using the established Mini build and QMP
runtime workflow.

- Positive controls and contrary evidence are recorded in the FLR-0383 ticket.
- FLR-0382 is moved to Waiting because the user prioritized direct application
  of the proven material. Its live trace comparison is unresolved, not failed.

## Decision

Proceed with an opt-in all-Sequoia-primitives override based on the existing
blue UNLIT positive control. Do not repeat the already tested per-instance
production color override or the one-primitive FLR-0326 material replacement.
Keep the unmodified production path as the default when the new flag is absent.

### Hypotheses

- If default material/shading is the differentiator, all Sequoia primitives
  will become visible in blue while the HUD remains visible in a live QMP frame.
- If binding is proven but the live vehicle ROI remains absent, the failure is
  downstream of material selection or the geometry is outside visible pixels;
  the next ticket must use this run's evidence to select the narrow boundary.
