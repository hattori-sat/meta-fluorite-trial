### Static API relationship map

- The current Example Demo's `poGetFilamentScene()` builds one persistent
  `SceneView` with empty models, the FLR0139 self-made Cube, a fixture Camera,
  and no explicit Skybox. The native platform view is therefore not receiving
  the production Playground/Planetarium model lists in this trial.
- The `Scenes` menu changes only the Flutter `StatefulSceneView` control
  widget. It does not rebuild the persistent `SceneView` or call
  `SceneController.updateFilamentScene`; a menu click cannot be treated as a
  native scene transition.
- Dart `SceneView` maps to the
  `com.toyotaconnected.filament_view.channel_3d_scene` platform view. Native
  registration creates a `ViewTarget` with a separate Wayland child surface,
  places its subsurface above the Flutter parent, creates a transparent
  swapchain, and selects `TRANSLUCENT` unless the diagnostic opaque variable
  is set.
- Native scene deserialization maps `scene`, `models`, and `shapes` into the
  ECS systems and applies the deserialized camera. An absent Skybox selects
  the default transparent Skybox after the initial system setup.
- The `unlitUV` material is transparent and requires `baseMap`; the FLR0139
  helper change satisfied that required Dart/native material input and made
  the Cube visible.

## Iteration 1 — same-run HUD-to-Cube composition boundary (2026-09-13)

### Facts

- The fixed FLR0139 image and normal-Dart launch were run once under the
  single-QEMU harness. Preflight, start, guest-ready, serial launch,
  early/late QMP capture, bounded marker collection, and QMP quit/cleanup all
  passed.
- Early QMP PPM SHA-256:
  `b29cf637cc495d62ba0ea252148b7595e26f89ff7d4a2208b1646b43f17537ba`.
  Late QMP PPM SHA-256:
  `481442329d0e5517eeeed016b3fd18f8b94294bb0f503c082479cfc40edee0c4`.
- Early fixed region `[300,250,620,400]` was uniform black while the HUD was
  visible. The late region had `217400` changed pixels and edge bounding box
  `[525,302,232,202]` while the HUD was absent.
- Runtime counts were `application=1`, `shape_ready=1`,
  `camera_applied=1`, `begin_true=147`, `render_return=147`,
  `end_frame=147`, `target_draw2=1063`, `vk_present=588`, `errors=0`.
- The bounded target markers contain `swapchain=true`, `extent=1280x800`,
  `index_count=3`, and repeated `FLUORITE_VK_PRESENT_CALL_RETURN result=0`.
- A remote diagnostic query initially failed because the Mini image does not
  provide `rg`; the same bounded query was reissued with standard `grep` and
  succeeded. No runtime process or QEMU state was changed by that failed
  query.

### Inferences

- The same run proves that the self-made Dart Cube is still rendered and
  presented. The apparent 3D disappearance is a final-frame
  composition/timing change, not a proven renderer stop.
- The delayed appearance of the child surface is consistent with ViewTarget
  committing a separate subsurface above the Flutter parent.
- The Mini effective source confirms that transparent renderer clear and
  transparent Filament swapchain patches are present; a missing clear patch is
  falsified for this image.
- Static API comparison found that Dart sends custom `UPDATE_FILAMENT_SCENE`
  and generated camera methods that are absent from the current native
  `FilamentViewApi`. The initial `scene.camera` deserialization path is the
  only camera path evidenced by `camera_applied=1`.

### Hypotheses

- H1: the committed child surface has an opaque/effectively opaque alpha
  contract or covers the parent HUD because it is above the parent.
- H2: surface commit/flush or activation timing makes the early parent-only
  and late child-only frames. The same-run early/late observation supports H2.
- H3: Flutter parent and Fluorite child use separate Wayland surfaces whose
  composition contract is not unified. H1 and H3 remain open.

### UNKNOWN

- The exact owner of the late white background is not proven: child buffer
  alpha, Vulkan `compositeAlpha`, parent background, or compositor policy.
- The exact event that switches from HUD to Cube is not timestamped at the
  Wayland commit/flush boundary.
- Production Playground/Planetarium payload delivery and native scene
  transition remain unverified.
- It is not yet decided whether a future transition fix should add a native
  scene-update protocol, rebuild the platform view with initialization data, or
  use both; this is deliberately outside the current composition evidence
  unit.
