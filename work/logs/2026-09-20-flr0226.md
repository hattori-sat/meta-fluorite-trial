## Inferences

- The original patch mismatch loop was a workflow-state error: a source
  change commit was made before `devtool modify --no-extract` established the
  baseline, so `initial_rev` pointed at the changed commit and
  `update-recipe` correctly emitted no patch.
- An interrupted normal `devtool modify` left only its temporary extraction
  marker in the workspace append. That incomplete marker prevented the later
  official `--no-extract` registration until it was moved to attic.
- The correct deterministic sequence is:
  complete effective source baseline → official `modify --no-extract` → edit
  source → `git add .` → source commit → official `update-recipe` → official
  finish → canonical layer registration.
