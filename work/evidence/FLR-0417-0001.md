## Inference

The strongest explanation for the capture failure is that the READY branch in
the guest marker command invokes `exit 0`, terminating the serial login shell
before `serial-exec` can append `rc` and its unique completion marker. The
following ticket tests this protocol under the shell wrapper; it does not assume
that graphics or the observer itself is healthy.
