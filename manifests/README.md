# Source manifests

This directory stores fixed source revisions, external-layer locks, and sanitized capture hashes. It does not store credentials or host-specific checkout paths.

- `agl-trout-fixed.xml`: 35 AGL repo projects pinned to commit hashes.
- `external-layers.lock`: fixed source for layers outside the AGL repo manifest.
- `baseline-sources.lock`: hashes for tracked manifest, conf, and the project-owned `meta-fluorite-trial` layer evidence.
- `build-config/`: privacy-sanitized manifests generated by the fixed-revision `aglsetup.sh` runs.
- `local-changes/`: allowlisted source-tree differences that must be explained separately from the manifest.

The raw and tracked `meta-fluorite-trial` tree hashes differ because patch author/trailer identity metadata was anonymized. The `meta_fluorite_trial_*` hashes fix the exact tracked bytes and preserve the content/provenance comparison after normalizing only identity metadata lines.
